<seatview-preview> integration example

A plain HTML page standing in for an operator's booking site. The seat map on the left is the host's own markup. The component only receives the selected seat and an auditorium configuration, and reports back through DOM events.

Integration code

          
<script type="module" src="https://seatview-3d.vercel.app/sdk/seatview.js"></script>

<seatview-preview id="preview"
  config-url="/auditoriums/room-3.json"
  brand="Your Cinema"></seatview-preview>

<script>
  const preview = document.getElementById('preview');
  viewButton.onclick = () => preview.open(selectedSeatId);
  preview.addEventListener('seatview-viewpoint', (e) =>
    analytics.track('seat_preview', e.detail));
</script>
